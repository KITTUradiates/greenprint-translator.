1. Online translation engine

The verified GreenPrint translation memory is bundled. Known text is translated locally without an API call; Gemini is used only for new or changed player-facing strings.

Personal-use setup: the key is held in this page's memory and is not saved to the website or addon. A browser-based app cannot keep a client-side API key secret from someone who can inspect the page or its requests. Do not share this page while your key is entered. For a public multi-user website, use a private backend proxy.

    How to use it on Android

    1
    Upload all files from the website ZIP to one GitHub repository and enable GitHub Pages. Open the HTTPS Pages link in Chrome. The included README has exact Android setup steps.
    2
    Paste your Gemini API key if the selected variant contains text not already in the built-in memory. Gemini 3.8 Flash is the recommended model.
    3
    Tap the addon selector and choose the latest Spanish GreenPrint `.mcaddon`.
    4
    Tap Scan, translate and verify. Known text is reused; only new/changed text is sent to Gemini.
    5
    Review the translation list and validation report, then download and import the new `.mcaddon` into Minecraft.
    Test each new build in a disposable world first. Static validation can catch syntax and archive damage, but it cannot prove that every Minecraft interaction works in-game.
